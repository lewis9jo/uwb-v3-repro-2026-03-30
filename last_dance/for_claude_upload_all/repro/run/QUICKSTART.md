# Quickstart

1) 필수 환경 준비
- Python 3.10+ 설치
- 가급적 가상환경 생성

2) 의존성 설치
- requirements.txt 필요
  - `pip install -r .\requirements.txt`

3) 모델 코드 실행
- 기본 실행 스크립트: run.ps1
- 핵심 실행 파일: `code\run_v3_final.py`

4) 빠른 점검
- 실행 전 로그/에러 확인: `python -m py_compile` 사용 가능

5) 실행 예시 (PowerShell)
- `cd "for_claude_upload_all\repro/run"`
- `powershell -ExecutionPolicy Bypass -File .\run.ps1`

6) 참고
- 핵심 코드 위치: `code`
- 문서 위치: `doc`
